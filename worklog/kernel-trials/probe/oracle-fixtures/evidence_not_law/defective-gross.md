# Receipt — standing rules for receipts

## Rules for every receipt

- Always run the full unit suite before handing work to a reviewer.
- Every receipt must link a log for each command it names.
- A reviewer must always inspect the tree before approving a change.
- Never mark a change as established without a second reviewer.
- Task cards must always use the shared template.

## Rules for captured checks

- Always run build, typecheck, lint and the unit tests, in that order, on every change.
- Logs must be kept for every run and must never be deleted.
