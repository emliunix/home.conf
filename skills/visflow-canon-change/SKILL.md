# Move canon

1. **Record-first** — enumerate what has been run about the sentence (the programme’s `evaluate/` files, its gate ledger) before amending or relying on it.
2. **The evaluate selects** — write the file that selects the change; canon moves only when an `evaluate/` file selects it.
3. **Amend and cite** — the new sentence cites that evaluate file.
4. **Correct in place** — a prediction the run contradicted is corrected where it stands, with the record saying so.
5. **Ratchet the check** — the amended sentence gains or tightens the cell that would go red if it drifted (see `visflow-gate`).

A document that contradicts the evidence is a defect; when an evaluate reverses a canon decision, amend the canon and cite the evaluate — never correct the evidence to fit the document.
