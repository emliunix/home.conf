## Process cost and trap paths

Two failed runs took 302.31 and 303.76 seconds, followed by a corrected-but-still-slow run of about 302 seconds: roughly 908 seconds before the bounded-read fix, excluding investigation. The first two exposed independent assertion and ordering defects. After the second slow result, the smaller listener-liveness probe was the cheapest discriminating move; future repetitions should use it as the stop rule instead of rerunning the five-minute test unchanged.

Rejected candidates: promoting the observed shutdown behavior to a machine-wide environment rule, because the evidence identifies a service listener defect; creating a new open-work register, because no existing register was established; and claiming compiler-error archaeology is always invalid, because the evidence supports only this fixture-authoring scope.
