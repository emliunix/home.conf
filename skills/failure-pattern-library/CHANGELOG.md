# Changelog

## 0.1.0 — 2026-10-17

First version.

- `SKILL.md`: capture and consult routes, and the **path rule as the skill's lead** — guidance names no
  project, repository, or PC path, only the general library root
  `~/Documents/process-failure-patterns/<project>/`.
- `references/criteria.md`: two criteria, **split by kind** — criterion 1 is *admission* (decidable at capture
  time) and criterion 2 is *classification* (requires recurrence, which cannot exist yet at capture time).
  The split is the substantive point: applying them as one kind excludes every new observation.
- `references/entry-template.md`: fields chosen so each criterion is evaluable, including the two no existing
  entry carries.
- `tests/l0.py`: the lint that keeps the list and the template in agreement, with a nine-seed census in
  `tests/seeded-defects.md`.
